## Tools and originality
- Any game engine, any combination of coding agents, tools, CLIs and MCPs.
- Orientation slide: "Any engine, any assets" and "No stealing".
- **Blatant plagiarism means disqualification.** This covers directly copying assets or source code, and copying entire mechanics without any uniqueness.
- Engines the organizers suggested ("Chef's pick"): Phaser, Kaboom.js, Three.js, plain HTML5 + JS. This project uses Phaser.

## Themes
- Three themes: **Fire, Shadow, Time**.
- At least one is required; using all three is optional.
- Themes are not genres. Work them into the **gameplay, storyline and atmosphere**.

## Submission
1. Google Drive link to the trailer video.
2. Public GitHub repo with **all source code and assets**.
3. Deployed game URL (optional).

## Trailer
- Evaluation is based on a **three-minute trailer**.
- **Two of the three minutes must be actual gameplay, directly screen-recorded.**
- Up to one minute of stylistic editing and graphics is encouraged, and it can be spread through the trailer.
- The trailer must **detail exactly how the themes were incorporated** into the game.
- Initial evaluation is done **solely on the trailer**.

## Evaluation
- **30% theme adherence:** Core Integration (15), Multi-Theme Synergy (10), Atmospheric Framing (5).
- The rest, with no weights given: Core Gameplay & Feel, Visual Polish, Audio Design, Innovation & Uniqueness, Technical Stability, Scope & Completeness, Trailer Quality.
- The **top 5 games by trailer** are shortlisted, and judges play those to pick the winners.
